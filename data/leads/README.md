# Pistes d'enquête (`data/leads/`)

Déposez ici une fiche **JSON** ou **YAML** par piste, validée par `npm run validate`.

Copiez `lead.template.yaml`, renommez (ex. `marches-place-vendor-x.yaml`), remplissez **proof_url** (source primaire publique) et ouvrez une PR.

Les fichiers `*.template.*` sont ignorés par la validation CI.
