## 1) DOGE targets → French vocabulary

| DOGE-style target | French public-sector equivalent |
|---|---|
| Improper payments | *Indus*, erreurs de liquidation, non-recouvrement (CAF, CNAM, CNAV, URSSAF) |
| Bloated / sole-source contracts | *Marchés publics*, avenants, UGAP, opérateurs, *sans publicité* / MAPA |
| Duplicate programs | Missions/programmes LOLF overlapping; *opérateurs* + collectivités + Sécu parallel aides |
| Benefit fraud | *Fraude sociale* (prestations + cotisations); multi-dossiers, fausse déclaration |
| Unused real estate | *Parc immobilier de l’État*, DIE, CAS immobilier, locaux vacants |
| NGO / subsidy abuse | *Subventions* associations (JOAFE, Data.Subvention, Chorus), missions asile/intégration |
| Tax gap / evasion | *Fraude fiscale*, contrôle DGFiP / DNLF, TVA carousel |
| Irregular stay / “braiding” | OQTF non exécutées, asile Dublin/réexamens, AME, *passeurs*/OLTIM, titres frauduleux, double identité |
| System gaming / integrity | Fraude documentaire (ANTS/CERT), multi-claim benefits, *procurations* / listes électorales, CNCCFP campaign accounts |

Actors: **État**, **Sécurité sociale**, **collectivités**, **opérateurs**, **marchés publics**, **subventions**, **aides sociales**, **fraude fiscale/sociale**.

## 3) Five hunting tracks (this week, public-records only)

### Track A — Marchés publics: same vendor, many buyers, odd avenants
- **Source:** PLACE CSV + BOAMP API
- **Method:** Load PLACE CSV; group by attributaire (SIRET if present / name normalize); flag (1) many ministries for same object keywords, (2) amounts just under European thresholds, (3) repeated awards same buyer–vendor year-over-year. Cross-check award notices vs result notices on BOAMP.
- **Hit looks like:** One SME / shell-like name with multi-ministry awards; vague object; large *tranche budgétaire* vs peers; award without competitive result trail.

### Track B — Subventions / NGOs (incl. immigration-integration operators)
- **Source:** Data.Subvention UI (public browse); JOAFE; Cour reports on associations immigration/intégration — https://www.ccomptes.fr/fr/publications/les-missions-le-financement-et-le-controle-par-letat-des-associations-intervenant-au ; PLF mission *Immigration, asile et intégration*
- **Method:** Pick top-funded associations in asile/hébergement/intégration; chart multi-financier stacking (État + département + ville); compare published *places* / unit costs to Cour unit-cost findings; flag dormant RNA / dissolved orgs still paid (where data allows).
- **Hit looks like:** Same board/SIRET chain across several subsidised shells; rising € without output metrics; Cour already flagged weak control.

### Track C — Social improper payments / multi-claim gaming
- **Source:** Cour certification SS; HCFiPS; CNAF/CNAM published control stats; open benefit scheme rules (service-public.fr)
- **Method:** Do **not** scrape personal CAF accounts. Instead: map which benefits are error-hot (RSA, PPA, APL, IJ) from Cour; collect published local *indus* patterns; use open address / SIRET / association data only to spot **publicly reported** multi-structure schemes (press + judgment + Cour).
- **Hit looks like:** Published judgment or Cour note of organised multi-dossier / false employer / false address rings; gap between evaluated fraud and recovery (HCFiPS €13bn vs €0.6bn).

### Track D — Irregular immigration: OQTF gap, asile spend, networks
- **Source:** Cour immigration PDF; Cour NEB Immigration 2024; Interior Rapport Parlement 2024 PDF; AN QE time series; OFPRA/CNDA annual reports; OLTIM / passeurs press releases (Interior)
- **Method:** Build a simple dashboard: measures pronounced vs executed (national + any département figures from QE); Mission 303/104 credits vs Ada / hébergement outturn; stock AME as imperfect proxy; list dismantled *filières* from official communiqués only.
- **Hit looks like:** Persistent <15–20% execution; hébergement/Ada overruns; Cour note that 20–30% of persons lack certain identity → removal blocked; documented passeur networks in official releases (not blogs).

### Track E — System integrity: ID docs + elections (facts only)
- **Source:** Cour titres d’identité; CERT prefecture bilans; Interior Rapport Parlement (document fraud chapter); Conseil constitutionnel AN decisions; CNCCFP campaign-account decisions
- **Method:** Quantify documented faux titres / fraudulent applications from official reports; for elections, scrape CC decisions for keywords *procuration*, *émargement*, *liste* — count **proven** irregularities vs rejected unproven claims; never escalate rumour.
- **Hit looks like:** CERT spike in false *justificatifs*; CC decision that actually deducted votes or annulled a race; CNCCFP rejection of accounts for illegal financing.
